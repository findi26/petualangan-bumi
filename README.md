# Petualangan Ke Bawah Tanah Bumi

Game edukatif interaktif untuk anak usia 6-10 tahun tentang 4 lapisan bumi (Kerak, Mantel, Inti Luar, Inti Dalam), dibintangi karakter Molie si tikus tanah.

## Fitur
- Poster teori interaktif (4 hotspot) sebelum bermain
- Peta level dengan lock/unlock
- Kuis pilihan ganda per level dengan narasi suara (Bahasa Indonesia)
- Bintang, poin, dan lencana
- Profil dan pengaturan (suara/musik/narasi)
- Progres tersimpan di localStorage

## Cara Menjalankan
Buka `index.html` di browser modern (Chrome/Safari/Firefox). Tidak perlu build.

Mode Guru (kelola materi, soal, gambar poster): buka `guru.html` (PIN default 1234). Data tersimpan di localStorage dan dibagikan dengan game (origin yang sama).
